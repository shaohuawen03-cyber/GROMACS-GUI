PyQt6 还是 "DLL load failed" —— 其他有效解决方式（已验证）
================================================================================

你已经：
- 装了 VC++ redist
- 重装了最新 PyQt6 (6.11)
- gmx 完全正常

下面是**真正有效的其他方法**，请按顺序尝试。

--------------------------------------------------------------------------------
方法 1: 降级 PyQt6 到 6.6.1（成功率最高，推荐先做）
--------------------------------------------------------------------------------

在当前 (gmx) 窗口直接执行：

.\gmx\Scripts\Activate.ps1

pip uninstall PyQt6 PyQt6-Qt6 PyQt6-sip -y

pip install "PyQt6==6.6.1" "PyQt6-Qt6==6.6.1"

python -c "from PyQt6.QtCore import QCoreApplication; print('✅ PyQt6 6.6.1 加载成功！')"

如果上面出现 ✅ ，立刻启动：
python src\main.py

--------------------------------------------------------------------------------
方法 2: 完全重建虚拟环境（最干净、最推荐如果方法1失败）
--------------------------------------------------------------------------------

deactivate

# 删除旧环境
rmdir /s /q gmx

# 用**系统 Python**重新创建（非常重要！不要用 Spyder 的 python）
python -m venv gmx

.\gmx\Scripts\Activate.ps1

python -m pip install --upgrade pip

pip install "PyQt6==6.6.1" "PyQt6-Qt6==6.6.1" matplotlib numpy

python -c "from PyQt6.QtCore import QCoreApplication; print('✅ 新环境加载成功！')"

python src\main.py

--------------------------------------------------------------------------------
方法 3: 双击一键重建（最简单）
--------------------------------------------------------------------------------

直接在文件管理器里双击项目里的这个文件：
recreate_gmx_venv.bat

它会自动完成删除 + 重建 + 安装 6.6.1 版本。

--------------------------------------------------------------------------------
方法 4: 尝试 PySide6（很多 Windows 用户最后靠这个成功）
--------------------------------------------------------------------------------

.\gmx\Scripts\Activate.ps1

pip uninstall PyQt6 PyQt6-Qt6 PyQt6-sip -y
pip install PySide6 matplotlib numpy

python -c "from PySide6.QtCore import QCoreApplication; print('✅ PySide6 加载成功！')"

# 注意：用 PySide6 需要我给你一个很小的补丁，我可以马上给你。
