================================================================================
根本原因分析
================================================================================

从你贴的日志：

Command line:
gmx.EXE pdb2gmx -f tai.pdb ... -ff oplsaa ...

Data prefix: C:\gmx2020.6_GPU     ← 错误！
Working dir: E:\1AI\GROMACS-GUI\test

真正可执行文件应该是：
E:\gmx2020.6_GPU\bin\gmx.exe

GUI 之前：
- 捡到了一个叫 "gmx.EXE" 的奇怪 launcher
- 没有正确设置 GMXDATA，导致 GROMACS 找不到 forcefield.itp

这就是 "No force fields found" 的真正原因。

# 3c54c8d fix: force real gmx.exe + auto set GMXDATA/GMXLIB

然后**完全关闭 GUI**，重新启动：

python src\main.py
