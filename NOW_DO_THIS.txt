================================================================================
PyQt6 仍然失败 —— 其他真正有效的解决办法（请按顺序做）
================================================================================

你已经装了 VC++ + 重装最新 PyQt6 都没用。

下面是目前最有效的其他办法：

--------------------------------------------------------------------------------
【最推荐 · 先执行这个】降级 PyQt6 到稳定版 6.6.1
--------------------------------------------------------------------------------

在你**当前这个 (gmx)** 窗口直接复制粘贴下面命令：

.\gmx\Scripts\Activate.ps1

pip uninstall PyQt6 PyQt6-Qt6 PyQt6-sip -y

pip install "PyQt6==6.6.1" "PyQt6-Qt6==6.6.1"

python -c "from PyQt6.QtCore import QCoreApplication; print('✅ PyQt6 6.6.1 加载成功！')"

如果上面出现 ✅ ，立刻启动：
python src\main.py

--------------------------------------------------------------------------------
【最彻底 · 成功率最高】完全重建虚拟环境（推荐）
--------------------------------------------------------------------------------

# 退出当前环境
deactivate

# 删除旧的 gmx 环境
rmdir /s /q gmx

# 用**系统 Python**重新创建（非常重要！）
python -m venv gmx

# 激活新环境
.\gmx\Scripts\Activate.ps1

# 升级 pip 并安装稳定版本
python -m pip install --upgrade pip
pip install "PyQt6==6.6.1" "PyQt6-Qt6==6.6.1" matplotlib numpy

# 测试
python -c "from PyQt6.QtCore import QCoreApplication; print('✅ 新环境 PyQt6 加载成功！')"

# 启动
python src\main.py

--------------------------------------------------------------------------------
【最简单】直接双击我准备好的文件
--------------------------------------------------------------------------------

在文件资源管理器里直接双击下面两个文件之一：

- `downgrade_pyqt6.bat`          （只降级当前环境到 6.6.1）
- `recreate_clean_venv.bat`      （删除旧环境 + 用系统 Python 重建 + 安装 6.6.1）

双击后等它跑完，再尝试启动：
python src\main.py
或直接双击 start_gmx.bat
