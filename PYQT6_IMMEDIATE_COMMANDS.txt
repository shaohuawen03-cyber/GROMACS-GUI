================================================================================
PyQt6 还是报 "DLL load failed" —— 立即可执行的命令
================================================================================

你已经确认 gmx 正常，现在重点解决 PyQt6。

请在**当前这个 (gmx) 窗口**直接复制下面命令执行。

--------------------------------------------------------------------------------
命令 1：直接降级到稳定版 PyQt6 6.6.1（最推荐，先试这个）
--------------------------------------------------------------------------------

.\gmx\Scripts\Activate.ps1

pip uninstall PyQt6 PyQt6-Qt6 PyQt6-sip -y

pip install "PyQt6==6.6.1" "PyQt6-Qt6==6.6.1"

python -c "from PyQt6.QtCore import QCoreApplication; print('✅ PyQt6 6.6.1 加载成功！')"

--------------------------------------------------------------------------------
命令 2：如果上面还是失败，执行下面干净重装
--------------------------------------------------------------------------------

.\gmx\Scripts\Activate.ps1
pip uninstall PyQt6 PyQt6-Qt6 PyQt6-sip -y
pip cache purge
pip install --no-cache-dir "PyQt6==6.6.1" "PyQt6-Qt6==6.6.1"

python -c "from PyQt6.QtCore import QCoreApplication; print('✅ 清理后加载成功！')"

--------------------------------------------------------------------------------
命令 3：完全重建虚拟环境（最彻底，成功率最高）
--------------------------------------------------------------------------------

# 先退出当前环境
deactivate

# 删除旧环境
rmdir /s /q gmx

# 用系统 Python 重新创建（重要！）
python -m venv gmx

# 激活新环境
.\gmx\Scripts\Activate.ps1

python -m pip install --upgrade pip

pip install "PyQt6==6.6.1" "PyQt6-Qt6==6.6.1" matplotlib numpy

python -c "from PyQt6.QtCore import QCoreApplication; print('✅ 新环境 PyQt6 加载成功！')"

python src\main.py

--------------------------------------------------------------------------------
双击重建（最简单）
--------------------------------------------------------------------------------

直接双击项目里的这个文件（我已经为你准备好）：
recreate_gmx_venv.bat

它会自动删除旧环境、创建新环境、安装稳定版 PyQt6。

--------------------------------------------------------------------------------
启动命令（测试成功后）
--------------------------------------------------------------------------------

python src\main.py

或者直接双击：
start_gmx.bat
