================================================================================
PyQt6 还是 "DLL load failed" —— 其他真正有效的解决办法
================================================================================

你当前在 (gmx) 环境，gmx 正常。

请**直接在当前窗口**复制下面命令执行（按顺序试）。

--------------------------------------------------------------------------------
【办法 1】降级到 PyQt6 6.6.1 （成功率最高，先做这个）
--------------------------------------------------------------------------------

.\gmx\Scripts\Activate.ps1

pip uninstall PyQt6 PyQt6-Qt6 PyQt6-sip -y

pip install "PyQt6==6.6.1" "PyQt6-Qt6==6.6.1"

python -c "from PyQt6.QtCore import QCoreApplication; print('✅ PyQt6 6.6.1 加载成功！')"

如果上面出现 ✅ ，立刻启动：
python src\main.py

--------------------------------------------------------------------------------
【办法 2】最干净：完全重建虚拟环境（推荐如果办法1失败）
--------------------------------------------------------------------------------

# 退出当前环境
deactivate

# 删除旧的 gmx
rmdir /s /q gmx

# 用系统 Python 重新创建（非常重要！）
python -m venv gmx

# 激活
.\gmx\Scripts\Activate.ps1

python -m pip install --upgrade pip

pip install "PyQt6==6.6.1" "PyQt6-Qt6==6.6.1" matplotlib numpy

python -c "from PyQt6.QtCore import QCoreApplication; print('✅ 新环境加载成功！')"

python src\main.py

--------------------------------------------------------------------------------
【办法 3】最简单：双击下面文件
--------------------------------------------------------------------------------

直接在文件资源管理器双击：
- recreate_clean_venv.bat   （推荐）
- downgrade_pyqt6.bat

双击后等它跑完，再试：
python src\main.py

或直接双击 start_gmx.bat
