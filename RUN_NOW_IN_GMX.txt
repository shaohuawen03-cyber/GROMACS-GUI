================================================================================
你现在在 (gmx) 环境，直接复制下面命令执行
================================================================================

【1】先尝试重新安装 PyQt6（当前窗口直接粘贴）
pip uninstall PyQt6 PyQt6-Qt6 PyQt6-sip -y
pip install PyQt6

【2】测试 PyQt6 是否能加载
python -c "from PyQt6.QtCore import QCoreApplication; print('✅ PyQt6 加载成功！')"

【3】如果上面成功，启动程序
python src\main.py

================================================================================
【强烈建议现在先跑这个】验证核心功能（不打开界面）
================================================================================

直接复制下面整段命令粘贴执行：

python -c "
import sys
sys.path.insert(0, 'src')
from core.config import get_gmx_path
from core.runner import GromacsRunner

print('GROMACS 路径:', get_gmx_path())
print()
r = GromacsRunner()
ok, out = r.run_command(['-version'])
print('gmx -version 测试成功:', ok)
print('输出前几行:')
print(out[:800])
print()
print('✅ 核心代码 + gmx 调用完全正常')
print('问题仅在于 PyQt6 图形界面加载')
"

================================================================================
如果第【2】步还是报 DLL 错误
================================================================================

你需要安装 Microsoft Visual C++ 运行库：

1. 打开浏览器下载这个文件：
   https://aka.ms/vs/17/release/vc_redist.x64.exe

2. 双击安装，一直点“下一步”。

3. 安装完后 **关闭当前 PowerShell 窗口**，然后重新打开执行：
   cd E:\1AI\GROMACS-GUI
   .\gmx\Scripts\Activate.ps1
   python -c "from PyQt6.QtCore import QCoreApplication; print('✅ PyQt6 加载成功！')"
   python src\main.py
