================================================================================
PyQt6 仍然 "DLL load failed" —— 最后有效的解决办法（按成功率）
================================================================================

你已经试过 VC++ + 重装最新版 → 无效。

下面是真正有效的其他办法（很多人在类似 Spyder 环境下靠这个解决）：

--------------------------------------------------------------------------------
【最高成功率】方法 1：降级到 PyQt6 6.6.1
--------------------------------------------------------------------------------

在你**当前这个窗口**直接执行下面命令：

.\gmx\Scripts\Activate.ps1

pip uninstall PyQt6 PyQt6-Qt6 PyQt6-sip -y

pip install "PyQt6==6.6.1" "PyQt6-Qt6==6.6.1"

python -c "from PyQt6.QtCore import QCoreApplication; print('✅ PyQt6 6.6.1 加载成功！')"

如果上面出现 ✅ ，直接运行启动：
python src\main.py

--------------------------------------------------------------------------------
【最彻底】方法 2：完全删除 + 用系统 Python 重建环境
--------------------------------------------------------------------------------

# 退出当前环境
deactivate

# 删除旧的 gmx
rmdir /s /q gmx

# 用**系统 Python**重新创建（非常重要！不要用 Spyder 的 python）
python -m venv gmx

# 激活
.\gmx\Scripts\Activate.ps1

# 升级 pip + 安装稳定版
python -m pip install --upgrade pip
pip install "PyQt6==6.6.1" "PyQt6-Qt6==6.6.1" matplotlib numpy

# 测试
python -c "from PyQt6.QtCore import QCoreApplication; print('✅ 新环境加载成功！')"

# 启动
python src\main.py

--------------------------------------------------------------------------------
【最简单】方法 3：直接双击我准备好的批处理文件
--------------------------------------------------------------------------------

在文件资源管理器里直接双击下面两个文件之一：

1. `downgrade_pyqt6.bat`          （只降级当前环境到 6.6.1）
2. `recreate_gmx_venv.bat`        （删除旧环境 + 全新创建 + 安装 6.6.1）

双击后等它自动跑完，再尝试：
python src\main.py
或双击 start_gmx.bat
