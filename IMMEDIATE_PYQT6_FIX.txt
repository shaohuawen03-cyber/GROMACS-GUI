PyQt6 还是 "DLL load failed" —— 其他真正有效的解决办法
================================================================================

你已经：
- 装了 VC++ redist
- 重装了 PyQt6 最新版
- gmx 完全正常

下面是**其他有效办法**，按推荐顺序。

--------------------------------------------------------------------------------
办法 1: 降级到 PyQt6 6.6.1 （成功率最高，先试这个）
--------------------------------------------------------------------------------

在你当前的 (gmx) 窗口直接粘贴执行：

.\gmx\Scripts\Activate.ps1

pip uninstall PyQt6 PyQt6-Qt6 PyQt6-sip -y

pip install "PyQt6==6.6.1" "PyQt6-Qt6==6.6.1"

python -c "from PyQt6.QtCore import QCoreApplication; print('✅ PyQt6 6.6.1 加载成功！')"

如果上面出现 ✅ ，立刻启动：
python src\main.py

--------------------------------------------------------------------------------
办法 2: 完全重建虚拟环境（最干净、最推荐如果办法1失败）
--------------------------------------------------------------------------------

# 退出当前环境
deactivate

# 删除旧的 gmx
rmdir /s /q gmx

# 用系统 Python 重新创建（非常重要！）
python -m venv gmx

.\gmx\Scripts\Activate.ps1

python -m pip install --upgrade pip

pip install "PyQt6==6.6.1" "PyQt6-Qt6==6.6.1" matplotlib numpy

python -c "from PyQt6.QtCore import QCoreApplication; print('✅ 新环境 PyQt6 加载成功！')"

python src\main.py

--------------------------------------------------------------------------------
办法 3: 最简单 —— 双击我为你准备好的批处理文件
--------------------------------------------------------------------------------

直接在文件资源管理器双击下面两个文件之一：

1. downgrade_pyqt6.bat          → 降级到 6.6.1
2. recreate_gmx_venv.bat        → 完全删除 + 重建 + 安装 6.6.1

双击后等它跑完，再运行：
python src\main.py

或直接双击 start_gmx.bat
