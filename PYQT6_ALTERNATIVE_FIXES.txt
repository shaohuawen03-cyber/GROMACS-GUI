================================================================================
PyQt6 DLL 加载失败 - 其他有效解决方案（按优先级排序）
================================================================================

你已经确认 gmx 正常，VC++ 也装了，但还是失败。

下面按成功率从高到低给你不同方案，直接复制执行。

--------------------------------------------------------------------------------
方案 1: 降级 PyQt6 到稳定版本（最推荐，成功率最高）
--------------------------------------------------------------------------------

在 (gmx) 环境执行：

.\gmx\Scripts\Activate.ps1

pip uninstall PyQt6 PyQt6-Qt6 PyQt6-sip -y
pip install "PyQt6==6.6.1" "PyQt6-Qt6==6.6.1" "PyQt6-sip<14"

python -c "from PyQt6.QtCore import QCoreApplication; print('✅ PyQt6 6.6.1 加载成功！')"

如果成功就启动：
python src\main.py

--------------------------------------------------------------------------------
方案 2: 降级到更老但极稳定的版本
--------------------------------------------------------------------------------

pip uninstall PyQt6 PyQt6-Qt6 PyQt6-sip -y
pip install "PyQt6==6.5.3" "PyQt6-Qt6==6.5.3"

python -c "from PyQt6.QtCore import QCoreApplication; print('✅ PyQt6 6.5.3 加载成功！')"

--------------------------------------------------------------------------------
方案 3: 完全重建虚拟环境（强烈推荐）
--------------------------------------------------------------------------------

# 退出当前环境
deactivate

# 删除旧虚拟环境
rmdir /s /q gmx

# 重新创建
python -m venv gmx

# 激活新环境
.\gmx\Scripts\Activate.ps1

# 升级 pip
python -m pip install --upgrade pip

# 安装依赖（使用稳定版本）
pip install "PyQt6==6.6.1" matplotlib numpy

# 测试
python -c "from PyQt6.QtCore import QCoreApplication; print('✅ 新环境 PyQt6 加载成功！')"

python src\main.py

--------------------------------------------------------------------------------
方案 4: 强制重新安装 + 清理缓存
--------------------------------------------------------------------------------

pip uninstall PyQt6 PyQt6-Qt6 PyQt6-sip -y
pip cache purge
pip install --no-cache-dir --force-reinstall PyQt6==6.6.1

--------------------------------------------------------------------------------
方案 5: 尝试 PySide6（很多时候比 PyQt6 好装）
--------------------------------------------------------------------------------

pip uninstall PyQt6 PyQt6-Qt6 PyQt6-sip -y
pip install PySide6

# 注意：如果想用 PySide6 需要改代码，这里先不推荐，除非上面都失败

--------------------------------------------------------------------------------
额外检查命令（请先运行这个）
--------------------------------------------------------------------------------

# 检查 Python 是不是 64 位
python -c "import sys; print('64-bit Python:', sys.maxsize > 2**32); print('Python路径:', sys.executable)"

# 检查当前 PyQt6 版本
python -c "import PyQt6; print(PyQt6.__version__); import PyQt6.QtCore; print('QtCore 模块路径:', PyQt6.QtCore.__file__)" 2>&1

================================================================================
推荐执行顺序：
1. 先运行“额外检查命令”
2. 尝试 方案1（6.6.1）
3. 如果不行，尝试 方案3（完全重建虚拟环境 + 6.6.1）

请把上面命令的输出贴给我，尤其是检查命令的结果。
