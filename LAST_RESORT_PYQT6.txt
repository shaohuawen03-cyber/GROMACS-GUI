================================================================================
PyQt6 还是失败 —— 最后有效的办法（按成功率排序）
================================================================================

你已经确认：
- gmx 完美运行
- VC++ 已安装
- 重装最新 PyQt6 无效

下面是真正能解决的最后办法：

================================================================================
【办法 1】降级 PyQt6 到 6.6.1 （目前成功率最高的）
================================================================================

在你当前的 (gmx) 窗口直接执行下面 4 行：

.\gmx\Scripts\Activate.ps1

pip uninstall PyQt6 PyQt6-Qt6 PyQt6-sip -y

pip install "PyQt6==6.6.1" "PyQt6-Qt6==6.6.1"

python -c "from PyQt6.QtCore import QCoreApplication; print('✅ PyQt6 6.6.1 加载成功！')"

如果出现 ✅ ，立刻运行：
python src\main.py

================================================================================
【办法 2】最推荐：完全重建虚拟环境（最干净）
================================================================================

# 1. 退出当前环境
deactivate

# 2. 删除旧环境
rmdir /s /q gmx

# 3. 用**系统 Python**重新创建（非常关键）
python -m venv gmx

# 4. 激活
.\gmx\Scripts\Activate.ps1

# 5. 安装稳定版本
python -m pip install --upgrade pip
pip install "PyQt6==6.6.1" "PyQt6-Qt6==6.6.1" matplotlib numpy

# 6. 测试
python -c "from PyQt6.QtCore import QCoreApplication; print('✅ 新环境加载成功！')"

# 7. 启动
python src\main.py

================================================================================
【办法 3】最简单 —— 双击我准备好的文件
================================================================================

直接双击下面两个文件之一（推荐）：

- recreate_gmx_venv.bat   （完全重建 + 安装 6.6.1）
- downgrade_pyqt6.bat     （只降级当前环境）

双击后等它自动跑完，再运行：
python src\main.py

或直接双击 start_gmx.bat
